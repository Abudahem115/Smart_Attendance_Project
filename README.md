# 🎯 Smart Attendance System (Face Recognition & Liveness Detection)

A professional, secure, and production-ready attendance system using **Face Recognition** and **Anti-Spoofing (Liveness Detection)**. Built with Python, OpenCV, and Supabase.

## ✨ Key Features

- **🛡️ Advanced Security**:
  - **Liveness Detection**: Prevents spoofing using photos or videos (**Blink/Open Mouth** challenges).
  - **Secure Storage**: All credentials stored safely in `.env`.
- **🕒 Smart Shift Logic**:
  - Automatically detects **Morning Check-In/Out** and **Afternoon Check-In/Out**.
  - **Bilingual Output**: Supports both English and Arabic status messages (e.g., *Morning Check-In (تسجيل دخول صباحي)*).
- **🚀 Production Ready**:
  - **Web Dashboard**: comprehensive admin panel for employee management.
  - **Text-Only Logs**: Clean, professional console output (no emojis) for easy parsing.
  - **Docker Support**: Containerized deployment for easy scaling.
- **☁️ Cloud Data**: Real-time syncing with **Supabase** (PostgreSQL).

---

## 🛠️ System Architecture

The system is divided into two independent components:

1.  **Web Dashboard (`run_web_server.py`)**:
    - The Admin Interface.
    - Used by HR/Admins to add employees, view reports, and manage settings.
    - Runs on **Waitress** (Production WSGI) at `http://localhost:8080`.

2.  **Attendance Terminal (`hardware/start_system.py`)**:
    - The AI Camera System.
    - Runs on the Raspberry Pi or Entry Terminal.
    - Scans faces, verifies liveness, and logs attendance.

## 📦 Installation & Setup

### Prerequisites
- Python 3.9 or higher
- CMake (required for building `dlib`)
- A Webcam or Raspberry Pi Camera

### 1. Clone the Repository
```bash
git clone https://github.com/Abudahem115/Smart_Attendance_Project.git
cd Smart_Attendance_Project
```

### 2. Create Virtual Environment
```bash
# Windows
python -m venv venv
.\venv\Scripts\activate

# Linux / Mac / Raspberry Pi
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configuration (.env)
Create a `.env` file in the root directory:
```ini
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_anon_key
SENDER_EMAIL=your_email@gmail.com
SENDER_PASSWORD=your_app_password
SECRET_KEY=secure_random_string
```

## 🚀 Usage

### 1. Start the Admin Dashboard
Run the web server to manage employees:
```bash
python run_web_server.py
```
> Access at: **http://localhost:8080**
> **Login**: Use the credentials you inserted into the database.

### 2. Start the Camera System (Attendance Terminal)
Run this on the device connected to the camera:
```bash
python hardware/start_system.py
```
> **Controls**:
> - Press **'q'** or **'ESC'** to exit.
> - Follow the on-screen prompts (**Blink/Open Mouth**) to verify liveness.

## 🐳 Docker Deployment

To run the Web Dashboard in a container:

1. **Build the Image**:
   ```bash
   docker build -t smart-attendance .
   ```

2. **Run the Container**:
   ```bash
   docker run -p 8080:8080 --env-file .env smart-attendance
   ```

## 🔒 Database Schema (Supabase)

Run this SQL in your Supabase SQL Editor:

```sql
-- Employees Table
create table employees (
  id bigint generated by default as identity primary key,
  name text not null,
  employee_code text unique not null,
  email text,
  department text,
  face_encoding jsonb
);

-- Attendance Table
create table attendance (
  id bigint generated by default as identity primary key,
  employee_id bigint references employees(id) on delete cascade,
  date text not null,
  time text not null,
  status text -- (Morning Check-In, Morning Check-Out, etc.)
);

-- Admins Table
create table admins (
  id bigint generated by default as identity primary key,
  username text not null,
  password text not null
);
-- Insert Admin User (Replace with your own secure credentials)
insert into admins (username, password) values ('your_username', 'your_secure_password');
```
